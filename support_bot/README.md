# Support routing Telegram bot

Этот бот собирает продуктовые идеи от пользователей: он просит подтвердить
условия о 20% от прибыли, принимает идеи только от согласившихся, отправляет
их в операторский чат в заданном формате и показывает три кнопки для
модерации запроса.

## Возможности

* Проверка согласия на условия (20% от прибыли) при запуске бота.
* Форматирование обращения: `" сообщение"`, строка `от кого (@username)`.
* Кнопки **Удалить**, **Заблокировать** и **Подтвердить** под каждым запросом.
* При подтверждении создаётся пригласительная ссылка в указанный чат поддержки
  с названием `Dep x <username>`; ссылка отправляется и в операторский чат, и
  пользователю.
* Возможность разблокировки через команду `/unblock <user_id>` в операторском
  чате.

## Как запустить

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Экспортируйте необходимые переменные окружения:

   * `BOT_TOKEN` – токен бота от `@BotFather`.
   * `ADMIN_CHAT_ID` – идентификатор чата операторов, куда будут приходить
     обращения.
   * `SUPPORT_CHAT_ID` – идентификатор супергруппы с включёнными топиками, где
     бот создаёт ссылки для общения с пользователями. Параметр опциональный, но
     без него кнопка «Подтвердить» не сможет отправить ссылку пользователю.

3. Запустите бота:

   ```bash
   python support_bot/bot.py
   ```

Убедитесь, что бот является администратором в обоих чатах (операторском и
support-группе) с правами на управление ссылками и создание топиков, иначе
кнопка «Подтвердить» не сможет сформировать ссылку для нового чата.
