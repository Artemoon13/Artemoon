# Telegram Support Bot

Бот помогает твиттер-инфлюенсерам обмениваться саппортом в общем чате. Он проверяет, что участник поддержал минимум 10 постов до того, как отправит свой, ограничивает количество публикаций двумя постами в сутки и следит, чтобы в чате оставались только ссылки на твиты.

## Возможности

- Автоматически удаляет любые сообщения в группе, кроме ссылок на твиты.
- Регистрация пользователя и привязка X/Twitter-аккаунта (`/twitter @handle` в личке с ботом).
- Отметка поддержанных постов (`/support <ссылка> [доказательство]` в личке).
- Подсчёт выполненных поддержек, суточных лимитов и автоматический «мут»/«анмут».
- Автоматическая проверка лайка или ретвита в Twitter перед засчитыванием поддержки.
- Команда `/status` показывает прогресс и долги, не засоряя общий чат.

## Настройка

1. Создайте бота у `@BotFather` и получите токен.
2. Склонируйте репозиторий и установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` рядом со скриптом и укажите настройки:

   ```env
   TELEGRAM_BOT_TOKEN=123456:ABCDEF
   SUPPORT_CHAT_ID=-100123456789  # ID вашего супергруппового чата
   SUPPORT_BOT_DB=data/support-bot.db
   TWITTER_BEARER_TOKEN=AAAAAAAA...  # ключ приложения X/Twitter с доступом к лайкам/ретвитам
   ```

   `SUPPORT_CHAT_ID` нужен, чтобы бот мог снимать «мут» с пользователей даже если они отправляют команды в личку.
   `TWITTER_BEARER_TOKEN` используется для проверки поддержки — нужен доступ к эндпоинтам `/2/tweets/:id/liking_users` и `/2/tweets/:id/retweeted_by`.

4. Запустите бота:

   ```bash
   python support_bot.py
   ```

SQLite-база создаётся автоматически в указанном пути. Рекомендуется сделать регулярное резервное копирование.

## Рабочий процесс

1. Участник запускает бота в личке (`/start`) и указывает свой X/Twitter через `/twitter`.
2. Перед публикацией поста он должен поддержать 10 свежих ссылок, отмечая каждую через `/support <ссылка>` в личке (дополнительно можно приложить доказательство).
3. Когда долг закрыт, участник публикует в общий чат одно сообщение, содержащее только ссылку на свой твит — бот автоматически добавит его в очередь.
4. За сутки можно добавить не более двух постов (счётчик обнуляется в полночь по UTC). Попытки нарушить правило приводят к мгновенному удалению сообщения и возврату в «мут».

## Дополнительные идеи

- Добавить команду модератора для ручного снятия/выдачи долгов (например, `/forgive <user>`) на случай спорных ситуаций.
- Реализовать экспорт очереди в Google Sheets или Notion, чтобы команда видела историю поддержек вне Telegram.
- Включить проверку лайков/репостов через Twitter API или scrapers, чтобы автоматически подтверждать поддержку без ручных отчётов.

## Примечания

- Для корректной работы бот должен иметь права администратора в чате.
- Ссылки на твиты должны быть в формате `https://twitter.com/<user>/status/<id>` или `https://x.com/<user>/status/<id>`.
- В одном сообщении допускается только одна ссылка без дополнительного текста — остальные варианты бот удалит.
